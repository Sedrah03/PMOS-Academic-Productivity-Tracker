# My Project App - CMES 2026

This is a personal project focused on building a mobile app that integrates Machine Learning (ML) for predictive user analytics. The goal is to collect daily data through the app and use it to train models like XGBoost and LSTM for my paper at the CMES 2026 conference.

## Current Progress: Sprint 1
Right now, I'm setting up the core infrastructure.
- Repo is initialized and connected.
- Data dictionary is being drafted.
- Ethics committee paperwork is organized and uploaded.

## How it works (The Plan)
The project is spread over 140 days (10 Sprints).
1. Foundation: Getting Firebase and Git ready.
2. Data: Pilot testing and cleaning the raw datasets.
3. Modeling: This is the main challenge. I'll be implementing K-Means for clustering, then moving into XGBoost for the heavy lifting.
4. Deep Learning: Using LSTM for time-series predictions.
5. Integration: Connecting the Python models to the app via an API.

## Tech I'm using
- Frontend: Mobile (Firebase Auth/Firestore)
- Data Science: Python, Scikit-learn, XGBoost, TensorFlow
- Deployment: FastAPI
